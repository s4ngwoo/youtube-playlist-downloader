# FFmpeg / ffprobe binary placeholder (LGPL builds)
Place platform-matched sidecars here (or run scripts/prepare-ffmpeg-sidecar.sh).

Target triple naming (Tauri externalBin):
- macOS Apple Silicon: ffmpeg-aarch64-apple-darwin , ffprobe-aarch64-apple-darwin
- macOS Intel:         ffmpeg-x86_64-apple-darwin , ffprobe-x86_64-apple-darwin
- Windows x64:         ffmpeg-x86_64-pc-windows-msvc.exe , ffprobe-x86_64-pc-windows-msvc.exe

Policy:
- Official releases ship **LGPL** FFmpeg (no --enable-gpl / no nonfree).
- Windows CI/release: BtbN FFmpeg-Builds `*-lgpl` zip
- macOS CI/release: build from FFmpeg source without GPL flags (see scripts/prepare-ffmpeg-sidecar.sh)
- Do not commit large binaries; prepare locally / in CI.

Unix: chmod +x after placing binaries.
