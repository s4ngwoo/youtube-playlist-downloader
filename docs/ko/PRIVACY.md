# 개인정보 처리방침

**최종 수정:** 2026-09-11  
**제품:** YouTube Playlist & Audio Downloader  
**개발자:** Lee SangWoo ([s4ngwoo.lee@gmail.com](mailto:s4ngwoo.lee@gmail.com))

영문 원문: [../PRIVACY.md](../PRIVACY.md)

이 문서는 데스크톱 애플리케이션(“앱”)이 정보를 어떻게 다루는지 설명합니다. 앱은 **로컬에서 동작하는 오픈소스** 도구이며, 클라우드 계정 시스템을 운영하지 않고 개인정보를 판매하지 않습니다.

## 요약

| 항목 | 처리 방식 |
| :--- | :--- |
| 계정 | 없음 — 로그인 없음 |
| 분석 / 광고 | 앱에 내장되지 않음 |
| 개발자에게 보내는 크래시 텔레메트리 | 앱이 전송하지 않음 |
| 데이터 위치 | 기본적으로 사용자 기기 내부(사용자가 달리 선택하지 않는 한) |

## 기기에 저장될 수 있는 정보

사용하는 기능에 따라 앱이 로컬에 보관할 수 있는 항목:

- **다운로드 폴더 경로** (`localStorage` 등)
- **다운로드 히스토리** (이전에 사용한 플레이리스트/영상 URL·제목) — Tauri 로컬 스토어 플러그인
- **애플리케이션 로그** — 앱 로컬 데이터 디렉터리(문제 해결용, 앱 내 로그 뷰어에서 확인 가능)
- **다운로드한 오디오 파일 및 선택적 ZIP** — **사용자가 지정한** 폴더
- 실행 중 메모리상의 UI 상태(URL 입력, 선택 트랙, 진행률 등)

앱에서 히스토리/로그를 지울 수 있는 기능이 있으면 이를 이용할 수 있고, 디스크상의 파일·폴더는 사용자가 직접 삭제할 수 있습니다.

## 네트워크 활동

메타데이터 조회와 미디어 다운로드를 위해 앱(및 번들된 `yt-dlp`, 시스템의 `ffmpeg` / 선택적 `Deno` 등)은 **사용자가 요청한** 제3자 서비스 — 주로 YouTube(및 관련 CDN) — 와 통신합니다. 해당 서비스에는 별도의 개인정보 처리방침과 약관이 있습니다.

앱은 다운로드 히스토리, 로그, 파일을 개발자 서버로 **의도적으로 업로드하지 않습니다**.

## 권한·접근

데스크톱 앱으로서 다음을 요청하거나 사용할 수 있습니다.

- **파일 시스템** — 선택한 다운로드 디렉터리 읽기/쓰기, 로컬 설정·히스토리·로그 읽기/쓰기
- **네트워크** — 메타데이터·미디어를 위한 YouTube(및 관련 엔드포인트) 접속
- **프로세스 실행** — `yt-dlp` 사이드카 실행, 시스템의 `ffmpeg`·`Deno` 감지/사용

## 아동

앱은 13세 미만(또는 해당 관할의 법정 최소 연령 미만) 아동을 대상으로 하지 않습니다. 해당 연령 미만이면 사용하지 마세요.

## 제3자 소프트웨어

앱은 `yt-dlp` 등 제3자 구성 요소를 포함하거나 의존합니다. 이들의 동작과 데이터 처리는 각 라이선스·정책의 적용을 받습니다.

## 변경

이 방침은 저장소에서 갱신될 수 있습니다. 중요한 변경 시 “최종 수정” 날짜가 바뀝니다. 법이 허용하는 범위에서, 변경 후 계속 사용하면 개정 방침에 동의한 것으로 볼 수 있습니다.
