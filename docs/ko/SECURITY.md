## 취약점 신고

보안에 민감한 내용은 **공개 GitHub 이슈로 올리지 마세요**.

대신 이메일: **[s4ngwoo.lee@gmail.com](mailto:s4ngwoo.lee@gmail.com)**

가능하면 다음을 포함해 주세요.

- 문제 설명과 잠재적 영향
- 재현 절차 또는 PoC
- 영향받는 버전 / 커밋 / OS
- 수정 제안(선택)

가능한 범위에서 접수 확인을 드립니다. **조정된 공개(coordinated disclosure)** 를 선호합니다.

## 범위 안내

이 앱은 로컬 명령을 실행하고 YouTube 다운로드(및 선택적으로 yt-dlp 오버라이드 갱신 시 GitHub)를 위해 네트워크를 사용합니다. 특히 다음 유형의 제보를 환영합니다.

- 선택한 디렉터리 밖으로의 경로 탐색(path traversal) 또는 예상치 못한 파일 쓰기
- 신뢰할 수 없는 입력을 통한 명령 주입
- URL 또는 사이드카 인자 처리의 불안전성

범위 밖 예시: 오직 업스트림 `yt-dlp` / 번들·시스템 `ffmpeg` / `Deno`만의 취약점(해당 프로젝트에 제보), 또는 이미 침해된 로컬 기기를 전제로 하고 앱 고유 공격 경로가 없는 경우.
